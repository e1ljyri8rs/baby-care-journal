# 胚胎碎片率正常范围？

胚胎碎片率正常范围？因此一般来说只要胚胎碎片率小于20%都是比较正常的，但胚胎碎片率并不是决定试管移植成功率的仅有因素，还要综合女性的身体素质和卵巢功能来看，有的女性胚胎碎片率30%但一次就移植成功了，也有女性碎片率低于10%但失败了的，因此胚胎碎片多也是有可能成功的。导致胚胎碎片率高的原因不仅有女性的身体因素还有心理原因，因此建议女性放平心态，比起纠结碎片率更重要的是调整好自己的身体和作息，保持良好的身体素质才能更顺利怀下宝宝。那么胚胎碎片率正常范围？看看专家怎么说。

相对于正常的胚胎，碎片率越高的胚胎出现染色体异常和基因遗传缺陷的概率会越高，因此胚胎的碎片率成为了判断胚胎质量的标志之一。根据碎片率判断胚胎质量的方法如下：

1. 一级胚胎，属于优质胚胎，其卵裂球折光正常，细胞大小均匀一致，碎片率一般在0%-5%之间，是试管婴儿移植中最容易成功的胚胎；

2. 二级胚胎，属于比较良好的胚胎，其卵裂球折光一般，细胞稍有不均，胚胎碎片率在6%-20%之间；

3. 三级胚胎，其中的细胞大小和形状已经有明显不规则，且碎片率一般在20%-50%之间，移植的成功率较低；

4. 四级胚胎，试纸细胞大小和形状严重不均匀，碎片率大于50%，一般是不用于移植的劣质胚胎。
